# A/B Testing Framework

Structured iteration strategy for optimizing cold email performance [source: raw/cold-email-resources.md].

## Iteration Strategy

- **Rounds 1-3 (Big changes)**: Test fundamentally different approaches to eliminate bad categories
- **Rounds 4-6 (Medium changes)**: Change 2-3 elements per test
- **Rounds 7+ (Small changes)**: Isolate single variables to fine-tune

## Hypotheses Worth Testing

1. Deliberate typo placed late in email (signals real human at scale)
2. Scarcity element ("only onboarding X more brands this quarter")
3. Shared identity ("as someone who's also spent too long in Ads Manager...")
4. Give-first approach (lead with a free insight before the CTA)
5. Direct offer specificity using prospect's ad count data

## Key Metrics

- **Open rate**: Subject line effectiveness
- **Reply rate**: Body copy + CTA effectiveness (target: >2% after 50 sends)
- **Bounce rate**: List quality (pause if >3%)
